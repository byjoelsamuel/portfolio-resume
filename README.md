# sanity.media

Showcase for x22, DriveSanity and SoundSplit.

Live at **https://byjoelsamuel.github.io/portfolio-resume/**

```sh
npm install
npm run dev     # local dev server
npm run build   # static build in dist/
```

Pushing to `main` deploys to GitHub Pages (`.github/workflows/pages.yml`).
Project info lives in `src/data.js`. Cover art in `public/art/` is dithered from each project's own screenshots.
